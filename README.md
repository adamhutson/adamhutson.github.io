# adamhutson.github.io

Retired. This repo used to hold the built output of adamhutson.com, published
from a separate Hugo source repo.

The site is now built and deployed from
[adamhutson/adamhutson.com](https://github.com/adamhutson/adamhutson.com)
directly, by GitHub Actions.

GitHub does not allow disabling Pages on a `<user>.github.io` repo, so rather
than leave a stale duplicate of the site serving here, this repo now serves a
redirect to adamhutson.com that preserves the requested path.

The previous built output remains in this repo's git history.
